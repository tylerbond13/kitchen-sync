# Cake World — Asset Library

> **437 sprites**, organized into 13 category folders (+ a `vision-inspo/` reference set).
> Click any filename to open the image. Generated from the live file tree.

**Aesthetic:** the whole `ks-cw-*` set is one look — gilded "storybook patisserie"
(gold scrollwork, pastel/pink marble, hearts, roses). The only genuinely *clean /
wooden / less-feminine* art is in **`backgrounds/`** (the wood play-board) and the
herringbone parquet in **`walls-floors/`** — so the "vibe" split is captured by those
folders rather than a top-level flowery-vs-wood split (which would leave one bucket nearly empty).
